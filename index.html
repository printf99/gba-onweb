ตั้งค่า

ธีม
เกมและเซฟบนคลาวด์ (GitHub ส่วนตัว · ฟรี)
ยังไม่ได้เชื่อมตอนนี้เซฟอยู่ในเครื่องนี้เท่านั้น
  1. เปิด สร้าง token ใหม่บน GitHub
  2. Repository access: Only select repositories → เลือก gba-saves
  3. Permissions → Repository → Contents: Read and write
  4. Expiration: เลือกนานที่สุด แล้วกด Generate และคัดลอกมาวางด้านบน

เกมที่เพิ่มจะอัปโหลดขึ้นคลาวด์ให้ เครื่องอื่นเห็นในคลังและแตะเพื่อดาวน์โหลดได้เลย · เซฟในเกมอัปโหลดอัตโนมัติทุกครั้งที่เปลี่ยน เก็บประวัติทุกเวอร์ชัน · ใช้เมนู Save ในเกมเป็นหลัก (save state ไม่ซิงก์)
