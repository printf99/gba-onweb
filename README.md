# GBA on Web

เว็บแอปเล่นเกม GBA / GB / GBC บนเบราว์เซอร์ ติดตั้งลงหน้าจอโฮมของ iOS และ Android ได้ ฟรีทั้งหมด

- **คลังเกม:** ใช้ดีไซน์ Liquid Glass แสดงภาพปกจริงจาก libretro-thumbnails และเปลี่ยนรูปปกเองได้
- **เกมในคลัง:** เก็บไว้ในเครื่อง กดเล่นต่อได้ทันที ในคอมลากไฟล์มาวางได้
- **เซฟในเกม:** บันทึกในเครื่องอัตโนมัติ และถ้าเชื่อมคลาวด์ จะซิงก์ขึ้น GitHub repo ส่วนตัว
- **โหลดเซฟเอง:** โหลดไฟล์ `.sav` หรือ `.state` ก่อนเริ่มเล่นได้
- **ระหว่างเล่น:** ปุ่ม “เมนู” หยุดเกมแล้วเปิดเมนู (จุดเซฟด่วน, เสียง, สั่นเมื่อกดปุ่ม, เริ่มเกมใหม่) · ปุ่ม “เร่ง” แตะครั้งเดียวเปิด แตะอีกครั้งปิด
- **ออฟไลน์:** เปิดครั้งแรกแล้ว ครั้งต่อไปเล่นได้โดยไม่ต้องต่อเน็ต อีมูเลเตอร์ EmulatorJS 4.2.3 (core mGBA) เก็บไว้ใน `emulatorjs/` ไม่ต้องพึ่ง CDN

## เซฟถาวร

เซฟในเกมเก็บได้ 3 ชั้น:

1. **ในเครื่อง:** เก็บใน IndexedDB ของเบราว์เซอร์ และขอให้เบราว์เซอร์เก็บข้อมูลแบบถาวร
2. **บนคลาวด์:** repo ส่วนตัว `gba-saves` บน GitHub
   - เก็บเป็นไฟล์ `saves/<ชื่อเกม>.srm` ซึ่งเป็นไฟล์เซฟดิบ เปิดกับอีมูเลเตอร์ตัวไหนก็ได้
   - อัปโหลดอัตโนมัติทุก 15 วินาทีเมื่อเซฟเปลี่ยน รวมถึงตอนสลับแอปและตอนกดกลับคลังเกม
   - เปิดเกมบนเครื่องอื่นจะได้เซฟล่าสุดเสมอ
3. **ประวัติทุกเวอร์ชัน:** การอัปโหลดแต่ละครั้งเป็นหนึ่ง commit ย้อนกลับไปเซฟเก่าได้จากหน้า commits ของ repo
   - ถ้าเซฟสองเครื่องชนกัน เวอร์ชันของเครื่องที่ถูกแทนที่จะสำรองไว้ใน `saves/conflicts/`

### ตั้งค่าคลาวด์ (ทำครั้งเดียวต่อเครื่อง)

1. สร้าง fine-grained token ที่ <https://github.com/settings/personal-access-tokens/new>
   - Repository access: **Only select repositories** → `gba-saves`
   - Permissions → Repository → **Contents: Read and write**
   - Expiration: เลือกนานที่สุด
2. เปิดแอป → ⚙️ ตั้งค่า → วาง token → เชื่อม

บน iPhone ให้ตั้งค่าในแอปที่เพิ่มลงหน้าจอโฮมแล้ว เพราะแอปบนหน้าจอโฮมแยกข้อมูลจาก Safari

ถ้า token หมดอายุ แอปจะแจ้งเตือน ระหว่างนั้นเซฟยังอยู่ในเครื่อง เมื่อสร้าง token ใหม่แล้ววาง แอปจะซิงก์ต่อให้

## รันในเครื่อง

```bash
python -m http.server 8137
```
